客室クラスのご案内

スウェーデン航空は全席がファーストクラス仕様。さらに極上の静寂をお約束する最高峰「ダイヤモンドクラス」を各便6席限定でご用意しております。

STANDARD ALL-SUITE

ファーストクラス / First Class

北欧の上質な木目とデュベ（羽毛布団）を誂えた、洗練のセミプライベート空間。全席がダイレクト通路アクセスを保証し、フルフラットベッドに早変わりする電動リクライニングシートを採用。最高級のスウェーデン製リネンが深い眠りへと誘います。

  • 全席フルフラットシート（180度開張）
  • 北欧名店シェフ監修のフルコースディナー
  • 27インチ4K大型エンターテインメントモニター
  • BYREDO製オーガニックアメニティキット
First Class Suite (3:2 Image Ratio)
EXCLUSIVE 6 SEATS ONLY (A1-C2)

ダイヤモンドクラス / Ultimate Diamond Suite

1機につきわずか6席（A1〜C2）限定。通路側に完全不透明の厚みのあるウォールナット＆真鍮防音スライドドアを装備し、ファーストクラスの3倍価値を誇る圧倒的な居住性と静寂を実現。贅をつくした最高峰の個室スイートです。

  • 完全不透明なウォールナット製防音スライドドア
  • Hästens（ヘステンス）製キングサイズ仕様ベッド
  • キャビア＆高級シャンパンの常時オンデマンド
  • 専任CAによるVIPナイトモード個別サービス
完全防音スイート
Diamond Private Suite (3:2 Image Ratio)

Corporate Information

会社概要

スウェーデン航空は、日本と北欧を結ぶ最高峰の国際プレミアム航空会社です。

企業理念・フィロソフィー

「北欧の静寂と、極上のおもてなし」

移動時間を単なる移動ではなく、至福のリラクゼーションと創造の時間に変えること。それが私たちの使命です。

完全全席ファーストクラスのこだわり

エコノミークラスを排し、機内全体のプライバシーと上質なサービス密度を極限まで高めた独自モデルを導入しています。

北欧クラフトマンシップ

インテリアからベッドライナー、機内食のテーブルウェアに至るまで、スウェーデン王室御用達ブランドとのパートナーシップを厳守しています。
